AfterQuery · Break the Agent

Can an AI agent fix a
jammed 3D-printed hinge?

cadfix: an RL environment where the agent edits real B-rep CAD parts through MCP tools. We ran Claude Sonnet 5.5 and Opus 5.5 (three tries per level) and replayed every step in 3D.

How it is scored

A working fix is only 40 % of the reward

0if any gate fails: broken solid, hinge or seal touched, protected zones cut, part rebuilt
0.3 + 0.1the lid opens to 110° with ≥ 0.3 mm clearance, and the parts still print
+ 0.6minimal change: full points within 1.15× the material of the best known fix, zero at 2×

The agent sees every requirement, the rule and its own changed volume. It never sees the fix or the reference volume.
